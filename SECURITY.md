# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through [GitHub's security advisories](https://github.com/Mondarth/fvtt-package-catalogue/security/advisories/new). You will get a reply within a week. Once a fix is released, the advisory is published with credit to you, unless you prefer otherwise.

The API keys the catalogue accepts are not secrets: they ship inside the clients that use them. A leaked key is not a vulnerability; a way to make the catalogue do more than serve public package data is.
