# Type

Mondarth's pages are set in the reader's own system face: quick to load, and at home on every device. Code and data
that line up are set in the system's monospace face.

## Setting text

- Body text is `font.size.body`, `font.line-height.body` (1.5), and runs no wider than `layout.content` (48rem).
- A page has one title (`font.size.title`), its `<h1>`. Headings below it step down in order, never skipping a level.
- Hints, captions and tables are `font.size.small`, and muted (`color.text-muted`) where they are secondary.
- Emphasis is `font.weight.strong`. Not capitals, which a screen reader may spell out, and not colour alone.
- Numbers that line up in columns use tabular figures: `font-variant-numeric: tabular-nums`.
