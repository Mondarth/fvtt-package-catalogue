# @mondarth/fvtt-package-catalogue

The Foundry VTT package catalogue's SvelteKit application: its API, its website, and the worker that keeps its database
up to date. It is not published to npm; each release is a container image, `ghcr.io/mondarth/fvtt-package-catalogue`.

See the [repository's README](../../README.md) and the documentation in [`docs/`](../../docs/).
